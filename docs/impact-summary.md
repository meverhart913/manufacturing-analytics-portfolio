# Business-Impact Evidence

| Work | Documented result | Public treatment | Evidence boundary |
|---|---|---|---|
| Finish-defect reduction | Lower rework and documented annualized savings | Qualitative result | Exact value private; financial substantiation not independently inspected |
| Heat-treatment utilization | Improved loading and documented annualized savings | Qualitative result | No extrapolation or combined portfolio savings total |
| Point-of-use hardware | Reduced cycle time and travel; annualized savings | Qualitative result | Exact operating figures private |
| Supplier development | Lower component cost, improved readiness, removed bottleneck | Qualitative result | No annualization from throughput assumptions |
| Shortage response | High on-time performance; prevented shutdowns | Qualitative result | Exact rate and policy settings private |
| Production document automation | Reduced manual preparation effort | Qualitative result | No monetized labor savings inferred |
| Inventory dashboard / Price Explorer | Working or implemented components | Technical progress only | No realized savings or adoption metrics established |
| Capacity demonstration | Fictional scenario results | Synthetic output only | Not an employer result |

Historical outcomes are traceable to private career records. The public portfolio does not publish exact employer metrics or derive ratios that would reconstruct them.
