# Data and Confidentiality

This repository is intentionally a **sanitized portfolio**, not a mirror of an employer environment.

## Excluded

- Employer-owned source code and internal application packages
- Customer names, sales orders, serial numbers, prices, and transaction history
- Internal database, server, network-share, and credential details
- Proprietary drawings, DXF files, material specifications, and controlled technical data
- Screenshots or exports containing non-public operational information
- Exact business rules when disclosure could expose proprietary manufacturing methods

## Included

- Generalized business problems and decision logic
- Independently written demonstration code
- Fictional data shaped to exercise the same analytical patterns
- High-level architecture and validation approaches
- Qualitative outcomes and deliberately non-specific performance summaries

## Interpretation

Project names and descriptions are used to explain my analytical approach. The public examples demonstrate transferable skills; they are not production releases and cannot be used to reconstruct an employer's systems or processes.
