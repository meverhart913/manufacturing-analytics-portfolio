# Selected Manufacturing Process Improvements

Analytics is most useful when it changes the process, not when it ends at a dashboard.

## Defect reduction

Led a Lean Six Sigma Green Belt project focused on reducing a recurring finish defect, with documented annual savings.

## Heat-treatment capacity

Analyzed component usage, batch quantities, and material sizes to improve equipment loading and document substantial annualized savings.

## Point-of-use staging

Redesigned point-of-use hardware staging to remove substantial operator travel, shorten cycle time, and document annual savings.

## Supplier and lead-time improvement

Reduced the cost of a recurring purchased component while also improving supplier lead time.

## Supply-risk response

Expanded safety-stock coverage for a critical bearing family and supported sustained on-time performance during supply risk.

## Common method

1. Translate the operational complaint into a measurable constraint.
2. Establish a baseline from process or ERP data.
3. Test the economic impact before recommending the change.
4. Implement with the people performing the work.
5. Verify the result after the process stabilizes.
