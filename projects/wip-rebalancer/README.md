# Sales Order WIP Rebalancer — Design

**Proposed MVP; no deployed recommendation engine or realized benefit claimed.**

## Problem

Manual backlog reviews must identify demand coverage, shortages, excess assignments, and opportunities to redirect appropriate material.

## Contribution and approach

Defined a recommendation-report concept connecting demand priorities with material readiness. The design separates suggested actions and reasons from ERP transactions. Production Control would review recommendations before action.

## Domain judgment

Physical readiness, eligibility, existing commitments, and demand priority all affect whether a reassignment is sensible. The public description intentionally omits employer-specific priority rules and production stages.

## Result

A scoped design, with implementation and acceptance still pending. It demonstrates requirements framing and planning judgment, not completed automation. It remains behind the active Price Explorer stability milestone.
